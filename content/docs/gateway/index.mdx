## 启动网关

```bash
lax serve
lax serve --addr 127.0.0.1:9000
```

前台运行，启动时仅统计账号与模型数量，不向上游发起请求。默认只监听回环地址。完整参数与输出见[系统命令](/docs/cli/system#serve)。

## 六条入站路径

路径决定入站协议，六条路径同时可用，单个网关可同时接入多类客户端：

| 入站路径 | 协议 | 常见客户端 |
| --- | --- | --- |
| `POST /v1/messages` | anthropic | Claude Code |
| `POST /v1/chat/completions` | openai-chat | 通用 OpenAI SDK 客户端 |
| `POST /v1/responses` | openai-responses | Codex |
| `POST /v1/embeddings` | openai-embeddings（向量化，见[向量化](/docs/gateway/embeddings)） | 需要向量化的 OpenAI SDK 客户端 |
| `POST /v1beta/models/{model}:generateContent` | gemini | Google SDK 与原生调用 |
| `POST /v1/systemone` | systemone（决策协议，见[决策请求](/docs/gateway/decision)） | TypeSafe SDK、`lax decide` |

gemini 的模型名不在请求体里，而在路径上。路径解析按三条规则：

| 位置 | 规则 |
| --- | --- |
| 模型名 | 取 `{model}` 这一段；请求体里即使带了 `model` 字段也不看 |
| `:` 之后的后缀 | 不属于模型名，只用来区分非流式（`generateContent`）、流式（`streamGenerateContent`）与向量化（`embedContent`） |
| 含 `/` 的名称 | 按路径段转义写出，`org%2Fgemini` 解析为 `org/gemini` |

`{model}` 的值参与选号：网关按这个名称挑一个账号，条件是账号声明提供该模型。候选规则见[选号依据](/docs/models#选号依据)。

两条 gemini 路径均只接受 POST，向量化的 `:embedContent` 同样只收 POST，其它方法返回 405 并携带 `Allow: POST`。

出站协议由账号决定，取值范围同为这六种；向量化只打供应商声明了向量化路由的那一条。留空时取供应商的[默认协议的确定规则](/docs/providers#默认协议的确定规则)。

入站与出站协议相同时走直通，不同时走统一表示转换，两条路径的边界见[直通与转换](/docs/gateway/conversion)。前四条协议之间的十六种组合均可用，流式与非流式都支持，工具调用包含在内；systemone 与向量化只做同协议直通。

## 只读接口

```bash
curl -s http://127.0.0.1:4567/v1/models
curl -s http://127.0.0.1:4567/v1/models/deepseek-v4-pro
curl -s http://127.0.0.1:4567/healthz
```

| 接口 | 返回 | 边界情况 |
| --- | --- | --- |
| `GET /v1/models` | 启用账号声明提供的模型清单，按名称去重升序，`owned_by` 为供应商名 | 一个模型都没有时仍是 200，`data` 为空数组 |
| `GET /v1/models/{id}` | 清单里的那一个对象，形状与列表项相同；`{id}` 是模型名原文，含 `/` 的名称也能取到 | 404，`error.type` 为 `not_found_error` |
| `GET /healthz` | 运维视角的计数：账号、启用账号、模型与进出协议，含停用账号 | — |

两个清单接口只读。它们只接受 GET，其它方法返回 405 并携带 `Allow: GET`。

调用它们不写请求记录，也不动冷却、失败计数与选号，因此可以拿返回值填客户端的模型下拉框，不会影响转发。

冷却指账号连续失败后被暂时移出候选的一段时间，规则见[冷却与失败转移](/docs/accounts/failover#冷却与失败转移)。

清单与转发对同一个名字可以给出不同结论。清单只反映「现在有账号声明提供这个名称」，转发时的 503 才表示「账号存在但当下打不通」。两种情形：

| 账号状态 | 清单 | 直接转发 |
| --- | --- | --- |
| 只有停用账号提供该名称 | 404 | 503 |
| 提供者处于冷却 | 照常出现 | 若仍在冷却则计入 503 |

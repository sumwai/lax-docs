版本按发布时间排列。每个版本只写使用者能看到的能力变化与必要的行为修正，不列内部重构与提交过程。

## v0.2.1

发布时间：2026-11-02

### 新增

- `lax route` 一组命令：`ls`、`show`、`set`、`unset`、`account`、`explain`。
- 五种选号策略：`priority`、`rotate`、`weighted`、`success`、`softmax`。
- 账号权重支持账号默认与按模型覆盖。
- `route explain` 可预演候选顺序、排除原因、权重、样本、成功率、延迟、得分与概率。
- 网关按模型读取选号策略与权重，并记录 `route_stats` 分钟桶。

### 行为

- 选号策略快照读取失败时返回 500，不静默回退到隐式顺序。
- `strict` 会话粘性在目标账号不可用时返回 503，不换号。
- 每个尝试继续各写一条请求记录，并计入选号统计。

## v0.2.0

发布时间：2026-11-02

### 变更

- 冷却从账号级改为账号 + 模型级。一个模型 429 不再影响同账号的其它模型。
- 冷却截止时间以 Unix 毫秒存储，429 的 500 毫秒档不会被截成 0。
- 运行时失败更新账号的最近错误，不覆盖探活结果。
- `account ls` 与 `model ls` 展示每个模型的冷却状态。

## v0.1.3

发布时间：2026-11-01

### 新增

- 内置供应商目录从二进制内置 JSON 读取，并记录来源：内置、插件、自建。
- `provider ls` 默认输出总览，`--verbose` 显示完整路径与模型列表地址。
- `plugin ls --available` 列出官方插件仓库中可安装的插件。

## v0.1.2

发布时间：2026-11-01

### 新增

- `plugin install` 与 `plugin update --source` 支持本地目录、GitHub 来源与官方插件名。
- 官方插件名支持 `name`、`name@version` 与 `name@ref` 三种写法。
- 下载与解包拒绝符号链接、特殊文件、重复条目与路径逃逸。

## v0.1.1

发布时间：2026-11-01

### 新增

- `usage`、`log tail` 与 `plugin logs` 支持统一的时间范围参数。
- `usage` 支持按账号、模型与供应商筛选，`--by day` 按时间升序。
- 正式 Release 自动部署到生产主机，健康检查失败时回滚。

### 修正

- `provider add` 与 `provider set` 的帮助与错误信息列全八条路由参数。

## v0.1.0

发布时间：2026-11-01

第一个发布版本。

### 功能

- 八条线协议：anthropic、openai-chat、openai-responses、gemini、systemone、openai-embeddings、openai-speech、openai-transcriptions。
- 四条对话协议之间的十六种转换，流式、工具调用与思考内容。
- 账号池、冷却、失败转移与模型探活。
- 插件运行时：声明式插件、内置方言与 `moejs` JS 沙箱。
- 模型别名、能力位、单价与账号覆盖价。
- 请求记录、用量汇总与花费估算。
- SQLite、PostgreSQL 与 MySQL 后端。
- 基于 `v*` tag 的版本推导与四个平台的发布包。

版本按发布时间排列。每个版本只写使用者能看到的能力变化与必要的行为修正，不列内部重构与提交过程。

## v0.2.5

发布时间：2026-11-17

### 新增

- `lax route policy` 一组命令：`ls`、`show`、`add`、`set`、`unset`、`rm`、`enable`、`disable`、`test`。
- 规则按账号、供应商、模型、状态码与错误文本匹配；命中后决定同账号重试、账号或账号-模型冷却、永久停用，以及返回还是换号。
- 内置兜底：401 停用并返回，402 停用并换号，400 或 403 命中计费关键词时停用并换号。
- `account ls` 显示账号级冷却；`account test` 命中规则时显示命中的策略与动作。
- 语音应错探活命中计费类停用或冷却规则时，不再把账号标成可用。

### 行为

- 没有规则命中时，原有失败转移行为不变；400、401、403 仍不进入 `route_stats`。
- 账号级冷却进入选号硬过滤，`route explain` 的理由写「账号冷却中」。
- 规则在每次客户端请求第一次失败时读取一次，改完立即生效。

### 修正

- 额度快照缺少限流窗口时，保留上一次的 5 小时与每周窗口，不再清空。

## v0.2.4

发布时间：2026-11-14

### 变更

- `quota show` 改为按区块输出：账号、额度、周期、限流窗口、上游与排障分开，空区块整块省略；剩余比例与限流窗口的已用比例都带进度条。
- 终端里状态与进度条带颜色，管道与 `--json` 不带 ANSI；设置 `NO_COLOR` 可以关闭颜色。

### 修正

- CommandCode 的 5 小时与每周限流窗口改从 `credits` 响应的 `windowLimits` 读取，`used` 超过 `cap` 时显示「已超限」；月限额按「余额 + 本期已用」显示。

## v0.2.3

发布时间：2026-11-14

### 修正

- `quota show` 默认只显示额度事实，不再把监控设置表叠在明细下面；监控设置改用 `quota show <账号> --settings` 查看。
- 到期提示改成「还剩 N 天」或「已到期」，不再显示 `warn` 这类内部动作名。
- 未知或不适用的项不再用 `-` 占行，`quota show` 只列这次有内容的项。
- 数据库日志改写到 stderr，`record not found` 这类正常分支不再混进命令输出，`--json` 也不会被日志前缀污染。

## v0.2.2

发布时间：2026-11-14

### 新增

- `lax quota` 一组命令：`ls`、`show`、`refresh`、`set`、`unset`，只读查看上游账号的余额与到期时间。
- 支持 CommandCode 与 DeepSeek 两类额度来源；DeepSeek 支持多币种，优先 CNY。
- `route set` 新增 `--quota-order` 与 `--quota-min-usd`，可让额度参与候选过滤与最终排序。
- `route show` 与 `route explain` 显示额度策略；`route explain` 在有快照时追加「额度 / 剩余 / 到期」三列。
- `serve` 可为 `auto_refresh=true` 的账号后台刷新额度，启动先刷一次，之后每 30 分钟一轮。

### 行为

- 额度功能默认关闭：`quota_order=off`、`quota_min_usd=0`、`auto_refresh=false`、`expiry_mode=warn`、`expiry_days=3`。不配置时选号行为与旧版一致。
- `--quota-min-usd` 只排除折合余额已知且低于阈值的账号；从未刷新、汇率未知或余额未知的账号保留。
- 额度排序在策略、会话粘性与 softmax 之后做稳定排序；`strict` 粘性被额度排除时仍返回 503，不换号。
- 额度刷新失败只更新快照状态，不停用账号、不写请求记录；只有真实转发请求收到 401 才停用账号。
- `source=off` 的账号旧快照不再参与选号，下一次刷新会清掉旧快照。

## v0.2.1

发布时间：2026-11-02

### 新增

- `lax route` 一组命令：`ls`、`show`、`set`、`unset`、`account`、`explain`。
- 五种选号策略：`priority`、`rotate`、`weighted`、`success`、`softmax`。
- 账号权重支持账号默认与按模型覆盖。
- `route explain` 可预演候选顺序、排除原因、权重、样本、成功率、延迟、得分与概率。
- 网关按模型读取选号策略与权重，并记录 `route_stats` 分钟桶。

### 行为

- 选号策略快照读取失败时返回 500，不静默回退到隐式顺序。
- `strict` 会话粘性在目标账号不可用时返回 503，不换号。
- 每个尝试继续各写一条请求记录，并计入选号统计。

## v0.2.0

发布时间：2026-11-02

### 变更

- 冷却从账号级改为账号 + 模型级。一个模型 429 不再影响同账号的其它模型。
- 冷却截止时间以 Unix 毫秒存储，429 的 500 毫秒档不会被截成 0。
- 运行时失败更新账号的最近错误，不覆盖探活结果。
- `account ls` 与 `model ls` 展示每个模型的冷却状态。

## v0.1.3

发布时间：2026-11-01

### 新增

- 内置供应商目录从二进制内置 JSON 读取，并记录来源：内置、插件、自建。
- `provider ls` 默认输出总览，`--verbose` 显示完整路径与模型列表地址。
- `plugin ls --available` 列出官方插件仓库中可安装的插件。

## v0.1.2

发布时间：2026-11-01

### 新增

- `plugin install` 与 `plugin update --source` 支持本地目录、GitHub 来源与官方插件名。
- 官方插件名支持 `name`、`name@version` 与 `name@ref` 三种写法。
- 下载与解包拒绝符号链接、特殊文件、重复条目与路径逃逸。

## v0.1.1

发布时间：2026-11-01

### 新增

- `usage`、`log tail` 与 `plugin logs` 支持统一的时间范围参数。
- `usage` 支持按账号、模型与供应商筛选，`--by day` 按时间升序。
- 正式 Release 自动部署到生产主机，健康检查失败时回滚。

### 修正

- `provider add` 与 `provider set` 的帮助与错误信息列全八条路由参数。

## v0.1.0

发布时间：2026-11-01

第一个发布版本。

### 功能

- 八条报文协议：anthropic、openai-chat、openai-responses、gemini、systemone、openai-embeddings、openai-speech、openai-transcriptions。
- 四条对话协议之间的十六种转换，流式、工具调用与思考内容。
- 账号池、冷却、失败转移与模型探活。
- 插件运行时：声明式插件、内置方言与 `moejs` JS 沙箱。
- 模型别名、能力位、单价与账号覆盖价。
- 请求记录、用量汇总与花费估算。
- SQLite、PostgreSQL 与 MySQL 后端。
- 基于 `v*` tag 的版本推导与四个平台的发布包。

lax 没有交互式界面。除 `serve` 常驻前台外，所有命令执行完即退出。

## 全局参数

| 参数 | 作用 | 默认值 |
| --- | --- | --- |
| `--json` | 以 JSON 格式输出到 stdout | 关 |
| `--config <路径>` | 指定配置文件 | `$XDG_CONFIG_HOME/lax/config.json` |
| `--db <路径>` | 指定数据库文件 | `$XDG_DATA_HOME/lax/lax.db` |

<Callout type="info">
三个全局参数写在子命令前后都生效，组级命令也接受。`lax --db ./lax.db account ls`、`lax account ls --db ./lax.db` 与 `lax account --db ./lax.db --help` 里的 `--db` 都会生效。
</Callout>

## 帮助

```bash
lax --help
lax help
lax help account
lax help account ls
lax account --help
lax account add --help
```

组级帮助列出子命令；子命令级帮助列出参数与示例。

`-h`、`--help` 与 `help` 在组级等价，`lax help <命令> <子命令>` 直接显示子命令帮助。不带子命令直接运行组（如 `lax account`）与 `lax account --help` 等价，内容写 stdout 并以 `0` 退出。

子命令级帮助（`lax <命令> --help` 或 `lax help <命令> <子命令>`）的用法文本写 stderr，命令结果仍写 stdout，脚本可以据此把帮助与结果分开。

## 命令一览

| 命令 | 作用 |
| --- | --- |
| `init` | 建配置目录、数据库与密钥 |
| `serve` | 前台启动网关 |
| `account` | 账号：`add`、`ls`、`set`、`rm`、`test`、`enable`、`disable` |
| `provider` | 供应商：`ls`、`add`、`set`、`unset`、`rm`、`header` |
| `model` | 模型：`ls`、`show`、`add`、`sync`、`probe`、`alias`、`price`、`capability`、`dialect`、`call`、`decide`、`speak`、`transcribe` |
| `route` | 选号：`ls`、`show`、`set`、`unset`、`account`、`explain`、`policy` |
| `quota` | 账号额度：`ls`、`show`、`refresh`、`set`、`unset` |
| `plugin` | 插件：`install`、`update`、`rollback`、`verify`、`logs`、`reload`、`config`、`ls`、`show`、`enable`、`disable`、`rm`、`doctor` |
| `usage` | 按账号、模型或日期汇总用量 |
| `log` | 请求记录：`tail` |
| `doctor` | 自检配置、目录、密钥、数据库与端口 |
| `version` | 打印版本 |
| `completion` | 生成 bash、zsh、fish 或 powershell 补全脚本 |

## 常用子命令参数

### serve

```text
lax serve [--addr <地址>] [--json]
```

`--addr` 默认 `127.0.0.1:4567`，临时覆盖配置里的地址。

加 `--json` 时 stdout 只输出一个启动对象，包含实际监听地址、账号数与模型数；启动后的网关、插件与额度刷新日志改写 stderr。脚本因此可以按行读取 stdout，不会在 JSON 后面撞上日志文本。

```json
{
  "accounts": 3,
  "addr": "127.0.0.1:4567",
  "models": 1
}
```

### account add

```text
lax account add <名称> --provider <供应商> --key <key> [--models <模型>] [--priority N]
```

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--provider` | 供应商名，必填 | — |
| `--key` | key；`-` 从标准输入读，留空读 `LAX_KEY` | — |
| `--models` | 逗号分隔的模型名 | 空 |
| `--priority` | 优先级，小的先试 | `100` |
| `--name` | 账号名，也可作为位置参数 | — |

### account set

```text
lax account set <名称> [--key <key>]
```

更换 API Key，不删号。`lax account update` 是同义词。

### provider add / set / unset

```text
lax provider add <名称> [--base-url <地址>] \
    [--anthropic <路径>] [--openai <路径>] [--responses <路径>] [--gemini <路径>] \
    [--systemone <路径>] [--embeddings <路径>] [--speech <路径>] [--transcriptions <路径>] \
    [--default-protocol <协议>] [--models-path <路径>] \
    [--auth-header <头名>] [--auth-scheme raw|bearer|bearer-semicolon] [--note <备注>]
```

```text
lax provider set <名称> [同上]
lax provider unset <名称> <字段> [<字段>...]
lax provider rm <名称> [--force]
```

`lax provider unset` 的字段可以用 `anthropic`、`openai`、`responses`、`gemini`、`systemone`、`embeddings`、`speech`、`transcriptions`、`models-path`、`default-protocol`、`auth-header`、`auth-scheme` 与 `note`。

### route

```text
lax route ls
lax route show <模型> | --default
lax route set <模型> | --default --strategy <策略> [参数]
lax route unset <模型> | --default
lax route account ls [<账号>]
lax route account set <账号> [--model <模型>] --weight N
lax route account unset <账号> [--model <模型>]
lax route explain <模型> [--session <会话键>] [--seed N]
lax route policy ls [--all] [--json]
lax route policy show <id> [--json]
lax route policy add [条件] [动作]
lax route policy set <id> [字段 ...]
lax route policy unset <id> <字段开关 ...>
lax route policy rm <id>
lax route policy enable <id> | disable <id>
lax route policy test --status <码> [--message <文本>] [--explain]
```

`route set` 参数：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--strategy` | `priority`、`rotate`、`weighted`、`success`、`softmax` | 必填 |
| `--sticky` | `prefer`、`off`、`strict` | `prefer` |
| `--temperature` | 浮点数 | `0.1` |
| `--explore` | 百分比，例如 `2` | `2` |
| `--score-priority` | 浮点数 | `0.4` |
| `--score-success` | 浮点数 | `0.5` |
| `--score-latency` | 浮点数 | `0.1` |
| `--window` | `90m`、`24h`、`7d`、`2w` | `1d` |
| `--min-samples` | 正整数 | `20` |
| `--quota-order` | `off`、`expiry_asc`、`expiry_desc`、`ratio_desc`、`ratio_asc`、`usd_desc`、`usd_asc` | `off` |
| `--quota-min-usd` | 不小于 0 的数 | `0` |

`lax route set` 会[整条覆盖](/self-hosted/route)该条策略配置，未显式传入的额度参数也会恢复为默认值。

`lax route policy` 只修改上游失败后的处理动作，不改变候选排序顺序。规则条件与动作见[失败处理](/self-hosted/route/failure)。

`lax route show` 的终端表格输出在表格后多一行 `额度排序：… / 最低折合 USD：…`。

`--json` 多 `quota_order` 与 `quota_min_usd` 两个字段。

### quota

```bash
lax quota ls [--json]
lax quota show <账号> [--settings] [--json]
lax quota refresh <账号> [--json]
lax quota refresh --all [--json]
lax quota set <账号> [参数]
lax quota unset <账号> [字段]
```

`lax quota ls` 列出所有账号的额度快照。没有快照的账号状态写「未刷新」，其余列写 `-`。

`lax quota show` 的默认输出：

| 项 | 行为 |
| --- | --- |
| 区块 | 账号、额度、周期、限流窗口、上游、排障；只显示本次有内容的区块与行 |
| 剩余比例 | 带进度条 |
| CommandCode | 总额标成「月限额」；5 小时与每周窗口显示已用 / 上限与已用比例进度条，超限标「已超限」 |
| 到期 | 周期结束标「还剩 N 天」或「已到期」；到期后的处理不在此显示 |
| 颜色 | 终端里状态与进度条带颜色；管道与 `--json` 不带 ANSI |
| `--settings` | 只显示监控设置（来源、汇率、自动刷新、到期处理、提前天数、额度地址），不读快照；按当前设置重新折算 USD，改过汇率后不需要重新刷新 |

`lax quota refresh` 手动查一次上游额度，没有 `--due` 参数：

| 项 | 行为 |
| --- | --- |
| 超时 | 每个账号最多等 30 秒 |
| 部分失败 | 只保留失败端点的旧值 |
| 跳过 | 不支持的供应商或 `source=off` 的账号跳过，不算失败 |
| 退出码 | 任一支持的账号整次刷新失败（凭据被拒或查询失败）为 1；部分端点失败不算 |
| 副作用 | 只写额度快照，不改账号状态，也不写请求记录（详见[账号额度](/self-hosted/route/quota)） |

`lax quota set` 参数：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--source` | `auto`、`commandcode`、`deepseek`、`off`；`auto` 按供应商映射 | `auto` |
| `--fx-rate` | 非 USD 币种折 USD 的手工汇率，必须大于 0 | 未设置 |
| `--auto-refresh` | `serve` 时是否定时刷新；`--auto-refresh=false` 关闭 | `false` |
| `--expiry-mode` | `warn`、`deprioritize`、`exclude` | `warn` |
| `--expiry-days` | 临近到期的提前天数，1 到 3650 | `3` |
| `--base-url` | 额度接口地址；只取协议、主机与端口 | 空，用供应商 `base_url` 的 origin |

表里的默认值是账号没有设置时的取值；不写某项时保留原值，不会回到默认。

`lax quota set` 只修改显式给出的项；一个参数都不给是用法错误。

修改 `--source` 会清除旧来源的快照。

`lax quota unset` 的字段是 `source`、`fx_rate`、`auto_refresh`、`expiry_mode`、`expiry_days` 与 `base_url`。

写字段时只恢复那一项；不写字段时清除该账号的全部监控设置。

完整说明见[账号额度](/self-hosted/route/quota)。

## 输出约定

- 默认终端输出与 `--json` 的成功结果都写 stdout。
- 错误文本、进度与运行日志写 stderr，两种输出不混在同一条流里。
- `--json` 失败时 stdout 为空，stderr 只有一个对象，四个键固定出现：`error`、`hint`、`command` 与 `exit_code`；没有建议时 `hint` 是空串。
- 空集合输出 `[]`，不是 `null`。
- `lax plugin logs --follow --json` 是 NDJSON 流：每行一个完整对象，没有新日志时不输出空 `[]`。
- `lax plugin config unset` 幂等：声明过但从未设置的键也以 `0` 退出，`--json` 返回 `"removed": false`。
- 凭据只显示掩码，不输出明文。

`--json` 失败示例：

```json
{"error":"尚未初始化，先运行 lax init","hint":"","command":"lax account ls","exit_code":1}
```

## 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 运行失败：上游错误、同步失败、探活无可用模型、额度刷新失败、`lax doctor` 有检查未通过、非 2xx 请求 |
| `2` | 用法错误：参数缺失、取值非法、参数名拼错、未知子命令 |

## 示例

常用命令组合：

```bash
lax --json account ls
lax account ls --json
lax --config ./config.json --db ./lax.db serve
lax route set deepseek/deepseek-v4.1-flash --strategy softmax --temperature 0.05 --explore 1
lax route explain deepseek/deepseek-v4.1-flash --session demo --seed 42 --json
lax quota refresh acct-c
lax quota ls --json
lax quota set acct-c --fx-rate 0.14 --expiry-mode deprioritize
lax route set deepseek/deepseek-v4.1-flash --strategy weighted --quota-order ratio_desc --quota-min-usd 1
```

---
title: 模型定价
description: 配置供应商级标价与账号覆盖价，估算本地请求日志中的 token 与语音花费
---

`lax` 不执行真实扣费，也不连接支付系统。

配置模型定价的唯一目的，是在 `lax usage` 统计中将请求记录里的 token、字符数与音频秒数换算为可读的估算花费。

## 什么时候需要配置定价

- **需要按日 / 按账号 / 按模型统计花费**：通过 `lax usage` 核对本地请求开销。
- **同一模型在不同账号有不同协议价**：例如 `acct-a` 走包月套餐（设覆盖价为 `0`）或专属折扣价，而其他账号沿用供应商官方标价。

如果不需要估算花费，可以完全跳过定价配置，请求转发不受任何影响。

## 最短配置命令

```bash
# 1. 设置供应商级标价（每百万 token）
lax model price set deepseek/deepseek-v4.1-flash --in 0.6 --out 2.2

# 2. 为指定账号设置覆盖价（例如套餐内或折扣价）
lax model price set deepseek/deepseek-v4.1-flash --account acct-a --out 2.5

# 3. 查看标价与账号生效价格
lax model price ls deepseek/deepseek-v4.1-flash --account acct-a

# 4. 清除单项价格（清除账号覆盖后会回退到供应商级标价）
lax model price unset deepseek/deepseek-v4.1-flash --account acct-a out
```

## 工作方式与进阶参数

### 1. 两级定价与生效顺序

价格挂载在「供应商 × 模型」或「账号 × 模型」上，按以下固定顺序解析：**账号覆盖价 → 供应商级标价 → 未定价**。

- 设置供应商级标价时，如果模型名在全局唯一，可省略 `--provider`；若多家供应商都有同名模型，需传入 `--provider <供应商>`。
- 设置账号覆盖价时，传入 `--account <账号>`（与 `--provider` 互斥）。
- `lax model price set` 只更新命令行显式传入的字段，未传入的保持原值；所有计费字段均未传入时报错（退出码 `2`）。

<Callout type="warn">
设置价格的模型必须先存在于模型目录中（由 `lax model sync`、`probe` 或 `add` 写入）。

设置账号覆盖价还要求该账号下已有该模型的记录。
</Callout>

### 2. 六类计费参数与回退规则

| 参数 | 计费对象 | 缺价时的行为 |
| --- | --- | --- |
| `--in` | 输入 token（每百万 token） | 记为未定价 |
| `--out` | 输出 token（每百万 token） | 记为未定价 |
| `--cache-read` | 缓存读取 token（每百万 token） | 回退到 `--in` 单价 |
| `--cache-write` | 缓存写入 token（每百万 token） | 回退到 `--in` 单价 |
| `--tts-char` | 语音合成字符（每百万字符） | 记为未定价 |
| `--audio-second` | 语音转写时长（每秒） | 记为未定价 |

思考 token 不单独计价。

上游将其单独上报时，`lax usage` 会单列展示；对于将思考计入输出 token 的上游（如 `anthropic`），`--out` 单价已覆盖该部分。

### 3. 阶梯定价（`--tier`）

当模型按输入上下文长度分段调价（例如超过 200K token 翻倍）时，可在 `lax model price set` 中通过 `--tier` 配置阶梯档位：

```bash
# 200k 以上档位统一按基础单价的 2 倍计费（默认 full 模式）
lax model price set claude-sonnet-4 --provider anthropic --tier 200k+ --multiple 2

# 显式配置多档上限与分段累计（split）模式
lax model price set claude-sonnet-4 --tier 200k --in 3 --out 15 --tier-mode split
lax model price set claude-sonnet-4 --tier inf --in 6 --out 22.5
```

- **档位阈值（`--tier`）**：支持 `200k`、`1m`、`32768` 等上限写法，也支持 `200k+`、`>200k` 与 `inf`（表示无上限尾档）。
- **计费模式（`--tier-mode`）**：`full`（默认，整次请求按命中档位全量计价）或 `split`（各档位区间分段累计）。
- **单价或倍率**：每个档位可直接指定 `--in` / `--out` / `--cache-read` / `--cache-write`，也可通过 `--multiple`（或 `--multiplier`）基于基础单价按倍率放缩。

删除或清空阶梯档位：

```bash
lax model price tier unset claude-sonnet-4 --tier 200k
lax model price tier clear claude-sonnet-4
```

### 4. 分时计费（`--window`）

针对夜间闲时折扣等分时计费场景，可通过 `--window` 为模型配置时间窗口：

```bash
lax model price set glm-4.6 --window off-peak --start 00:00 --end 08:00 --tz Asia/Shanghai --multiplier 0.5
```

| 参数 | 说明 | 备注 |
| --- | --- | --- |
| `--window` | 窗口名称（如 `off-peak`） | 传入任意分时参数时必填 |
| `--start` / `--end` | 起止时刻（`HH:MM`） | `--end` 支持 `24:00` |
| `--tz` | IANA 时区（如 `Asia/Shanghai`、`UTC`） | 留空时按系统本地时区 |
| `--days` | 生效星期（如 `sun,mon,sat`） | 留空表示每天生效 |
| `--multiplier` / `--multiple` | 价格倍率（如 `0.5`） | 也可直接传 `--in` 等具体单价覆盖 |

删除或清空分时窗口：

```bash
lax model price window unset glm-4.6 --name off-peak
lax model price window clear glm-4.6
```

### 5. 完整规则管理与试算（`rule` 与 `test`）

查看当前生效规则、导入完整 JSON 规则或整条清除：

```bash
lax model price rule show claude-sonnet-4 --account acct-a
lax model price rule set claude-sonnet-4 --file rule.json
lax model price rule unset claude-sonnet-4
```

配置完成后，可用 `lax model price test` 在本地试算单次请求费用（支持 `--at` 模拟请求时间以验证分时窗口）：

```bash
lax model price test claude-sonnet-4 --in 150000 --out 2000
lax model price test glm-4.6 --in 10000 --out 500 --at "2026-11-20 02:00"
```

### 6. 请求级费用快照与「免费（`0`）」/「未定价」

新请求在写入数据库时会按当时的有效定价规则计算并保存 `cost` 快照。

后续调整模型单价、阶梯或分时规则不会追溯修改历史请求记录的费用；对于快照功能上线前留下的历史记录，`lax usage` 在查询时仍按模型当前定价动态计算。

- **`0` 是合法价格**：表示免费或已包含在固定套餐内，终端显示 `0.00`，`--json` 中 `cost` 为数值 `0`。
- **未定价**：终端显示「未定价」，`--json` 中 `cost` 为 `null`。

汇总统计时，未定价的请求不会按 `0` 计入总花费。

`lax usage` 会在结果中提示有多少条未定价记录，并给出对应的补价命令。

<Callout type="info">
金额显示精度规则：默认终端输出中 `0` 写为 `0.00`，小于 `0.01` 保留四位小数，其余保留两位小数。

`--json` 输出中 `cost` 始终为数值或 `null`。
</Callout>

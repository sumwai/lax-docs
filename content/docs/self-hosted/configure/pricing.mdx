---
title: 模型定价
description: 配置供应商级标价与账号覆盖价，估算本地请求日志中的 token 与语音花费
---

`lax` 不执行真实扣费，也不连接支付系统。

配置模型定价的唯一目的，是在 `lax usage` 统计中将请求记录里的 token、字符数与音频秒数换算为可读的估算花费。

## 什么时候需要配置定价

- **需要按日 / 按账号 / 按模型统计花费**：通过 `lax usage` 核对本地请求开销。
- **同一模型在不同账号有不同协议价**：例如 `acct-a` 走包月套餐（设覆盖价为 `0`）或专属折扣价，而其他账号沿用供应商官方标价。

如果不需要估算花费，可以完全跳过定价配置，请求转发不受任何影响。

## 最短配置命令

```bash
# 1. 设置供应商级标价（每百万 token）
lax model price set deepseek/deepseek-v4.1-flash --in 0.6 --out 2.2

# 2. 为指定账号设置覆盖价（例如套餐内或折扣价）
lax model price set deepseek/deepseek-v4.1-flash --account acct-a --out 2.5

# 3. 查看标价与账号生效价格
lax model price ls deepseek/deepseek-v4.1-flash --account acct-a

# 4. 清除单项价格（清除账号覆盖后会回退到供应商级标价）
lax model price unset deepseek/deepseek-v4.1-flash --account acct-a out
```

## 工作方式与进阶参数

### 1. 两级定价与生效顺序

价格挂载在「供应商 × 模型」或「账号 × 模型」上，按以下固定顺序解析：**账号覆盖价 → 供应商级标价 → 未定价**。

- 设置供应商级标价时，如果模型名在全局唯一，可省略 `--provider`；若多家供应商都有同名模型，需传入 `--provider <供应商>`。
- 设置账号覆盖价时，传入 `--account <账号>`（与 `--provider` 互斥）。
- `lax model price set` 只更新命令行显式传入的字段，未传入的保持原值；所有计费字段均未传入时报错（退出码 `2`）。

<Callout type="warn">
设置价格的模型必须先存在于模型目录中（由 `lax model sync`、`probe` 或 `add` 写入）。

设置账号覆盖价还要求该账号下已有该模型的记录。
</Callout>

### 2. 六类计费参数与回退规则

| 参数 | 计费对象 | 缺价时的行为 |
| --- | --- | --- |
| `--in` | 输入 token（每百万 token） | 记为未定价 |
| `--out` | 输出 token（每百万 token） | 记为未定价 |
| `--cache-read` | 缓存读取 token（每百万 token） | 回退到 `--in` 单价 |
| `--cache-write` | 缓存写入 token（每百万 token） | 回退到 `--in` 单价 |
| `--tts-char` | 语音合成字符（每百万字符） | 记为未定价 |
| `--audio-second` | 语音转写时长（每秒） | 记为未定价 |

思考 token 不单独计价。

上游将其单独上报时，`lax usage` 会单列展示；对于将思考计入输出 token 的上游（如 `anthropic`），`--out` 单价已覆盖该部分。

### 3. 「免费（`0`）」与「未定价」的区别

- **`0` 是合法价格**：表示免费或已包含在固定套餐内，终端显示 `0.00`，`--json` 中 `cost` 为数值 `0`。
- **未定价**：终端显示「未定价」，`--json` 中 `cost` 为 `null`。

汇总统计时，未定价的请求不会按 `0` 计入总花费。

`lax usage` 会在结果中提示有多少条未定价记录，并给出对应的补价命令。

<Callout type="info">
金额显示精度规则：默认终端输出中 `0` 写为 `0.00`，小于 `0.01` 保留四位小数，其余保留两位小数。

`--json` 输出中 `cost` 始终为数值或 `null`。
</Callout>

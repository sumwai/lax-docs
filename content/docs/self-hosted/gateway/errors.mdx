---
title: 错误响应
description: 状态码、四种入站错误体与流式中断的收尾
---

错误体的形状由入站协议决定，不由上游协议决定。同一句错误发给 anthropic 客户端与 gemini 客户端时，字段不同。

## 状态码

| 状态 | 含义 |
| --- | --- |
| 400 | 请求不合法：模型名解析失败、协议不相通、缺少能力或路径参数错误 |
| 401 | 上游凭据被拒；账号会被停用 |
| 403 | 上游拒绝权限或套餐；原样返回，不停用账号 |
| 404 | 模型名不在清单，或路径不存在 |
| 405 | 路径存在但方法不对，带 `Allow` |
| 413 | 请求体超过上限 |
| 429 | 上游限流 |
| 500 | 网关内部错误，例如读选号策略或数据库失败 |
| 502 | 网关没有拿到上游响应，或方言构造失败 |
| 503 | 模型有提供者，但候选都失败或在冷却 |

## 四种错误体

### anthropic

```json
{
  "type": "error",
  "error": {
    "type": "not_found_error",
    "message": "清单里没有模型 x"
  }
}
```

`error.type` 取 `invalid_request_error`、`not_found_error`、`authentication_error`、`permission_error`、`api_error` 或 `rate_limit_error`。

### openai-chat

```json
{
  "error": {
    "message": "清单里没有模型 x",
    "type": "invalid_request_error",
    "param": null,
    "code": null
  }
}
```

### openai-responses

形状与 openai-chat 相同。`param` 与 `code` 显式给 `null`，因为 SDK 会读这两个键是否存在。

### gemini

```json
{
  "error": {
    "code": 404,
    "message": "清单里没有模型 x",
    "status": "NOT_FOUND"
  }
}
```

`code` 是本次 HTTP 状态码，`status` 由它映射：

| HTTP | status |
| --- | --- |
| 400 | `INVALID_ARGUMENT` |
| 401 | `UNAUTHENTICATED` |
| 403 | `PERMISSION_DENIED` |
| 404 | `NOT_FOUND` |
| 405 | `UNIMPLEMENTED` |
| 429 | `RESOURCE_EXHAUSTED` |
| 500 | `INTERNAL` |
| 503 | `UNAVAILABLE` |
| 其它 | `UNKNOWN` |

### systemone

```json
{
  "detail": {
    "error_type": "invalid_request_error",
    "message": "请求里的 model 不是 systemone 协议"
  }
}
```

字段名是 `error_type`，不是 `type`。

## 没有入站协议时

`/v1/models`、`/healthz`、405、未知路径与内部错误没有客户端协议可依，统一使用 anthropic 形状。

## 流式错误

流式已经开始后，错误以入站协议的事件帧发到流里：

| 协议 | 形状 |
| --- | --- |
| anthropic | `event: error` 加 `data: {...}` |
| chat | `data: {"error":{...}}` |
| responses | `response.failed` 一类错误事件 |
| gemini | 一条 `{"error":{"code":...,"message":...,"status":...}}` 帧 |

已经写出的字节收不回来，因此流式中断不会换号，也不会把同一个请求重发一遍。

## 错误文案

网关的错误消息说明发生了什么与下一步做什么，不只转述上游原文。上游错误会尽量解出 `error.message`，去掉重复的状态码与协议内部字段后返回。

排查入口：

| 命令 | 用途 |
| --- | --- |
| `lax log tail` | 看这一次请求的状态、账号与上游错误 |
| `lax model show` | 看模型在某个账号上的可达性与最近错误 |
| `lax route explain` | 看候选与排除原因 |
| `lax doctor` | 检查配置、数据库与端口 |

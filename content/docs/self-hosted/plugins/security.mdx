插件是第三方代码。

网关对插件运行时采取失败关闭策略：超出权限声明、无法访问或语法不支持的写法直接报错，不做静默降级。

## 两种信任级别

| 信任级别 | 对应运行时 | 执行方式 |
| --- | --- | --- |
| `declarative` | `declarative`（只有数据文件） | 不执行代码，宿主按 `dialects.json` 求值 |
| `sandboxed` | `moejs` | 每个 hook 在进程内 goja JS 沙箱执行 |

当前没有 `trusted-worker` 级别，也不开放文件系统、子进程与环境变量权限。

安装时 `--trust` 只是对 manifest 声明的确认，若与 `runtime` 不一致会直接报错。

## 沙箱能做什么

`moejs` 的 hook 接收固定上下文 `ctx`，并可调用以下宿主 API：

| API | 用途 |
| --- | --- |
| `lax.log([level], message)` | 写入插件日志（可通过 `lax plugin logs` 查看）与 `serve` 输出 |
| `lax.now()`、`lax.randomUUID()` | 获取当前时间与生成 UUID |
| `lax.base64.encode\|decode` | Base64 编解码 |
| `lax.sha256(text)`、`lax.hmacSHA256(text, key)` | 计算哈希与 HMAC 摘要 |
| `lax.error(code, message, {retryable?, details?})` | 构造标准错误对象 |
| `lax.http.request({...})` | 受网络权限约束的控制面请求 |
| `lax.cache.get\|set\|delete` | 进程内缓存，按插件隔离 |
| `URL` | 仅用于解析与格式化，不发网络请求 |

`console.log`、`console.info`、`console.warn`、`console.error` 也可用。

## 沙箱不能做什么

以下全局对象在沙箱加载时被移除：

```text
fetch          process        require        module
exports        Bun            child_process  XMLHttpRequest
WebSocket      fs             global         Buffer
setTimeout     setInterval
```

插件无法读取本地文件、系统进程、环境变量与账号凭据原文。

插件只能在 manifest 中声明接受哪种账号凭据（`api_key` 或 `bearer`），实际请求头仍由宿主按账号注入。

## 网络边界

`lax.http.request` 仅在 manifest 声明 `permissions.network.mode = "host-proxy"` 时可用，并受以下硬性约束：

- 只允许 `https`，禁止明文 `http`；
- 目标主机按精确域名或 `*.example.com` 匹配，禁止裸 `*`；
- 不跟随跨主机重定向；
- 方法只允许 `GET`、`POST`、`PUT`、`PATCH`、`DELETE`、`HEAD`；
- 单次请求超时 15 秒，每次 hook 最多 4 次请求、总计不超过 30 秒，响应体默认上限 `1 MiB`。

## 资源与超时上限

| 限制项 | 上限 |
| --- | --- |
| 单个 JS 源文件 | `4 MiB` |
| 一个插件的全部源文件 | `8 MiB`，最多 64 个文件 |
| 一次 hook 的返回值 | `8 MiB` |
| 注入的音频、媒体与流块 | `8 MiB`，超出置 `truncated` |
| 一个插件的 `lax.cache` | `1 MiB` |

`moejs` 没有 JS 堆内存硬上限，编写不当的插件仍可能拉高网关进程内存。

| hook | 默认超时 | 可配置上限 |
| --- | --- | --- |
| `prepare_request` | `100 ms` | `2 s` |
| `decode_response` | `2 s` | `30 s` |
| `decode_stream` | `100 ms` | `2 s` |
| 加载主模块 | `2 s` | — |

超时通过中断 JS 执行实现。

若卡在原生 Go 调用（例如 `lax.http.request` 等待上游响应）时不会立即返回，因此单次 hook 实际耗时可能超过上述毫秒数。

## 模块边界

插件只支持受限 ESM 语法，且被导入的模块必须位于插件根目录内（不能指向目录）：

| 支持 | 不支持 |
| --- | --- |
| `export function` / `export const` / `export class` | `import *` |
| `export default` 导出带 hook 方法的对象 | 裸模块名与 `node:` 内置模块 |
| 带扩展名的相对路径 `import` | 动态 `import()` |
|  | `export *`、`export { … }` |
|  | 顶层 `await` |

## 安全建议

- 只从可信来源安装插件；`--trust sandboxed` 是管理员确认，不是安全保证。
- 安装前先执行 `--dry-run` 核对插件将写入的供应商、路由、模型与权限。
- 插件包目录与数据库位于同一数据目录下，备份与迁移时一并处理。
- 敏感凭据不要写进 `options`，配置项只放非敏感参数。
- 升级前后使用 `lax plugin verify` 与 `lax plugin doctor` 检查包完整性与导出钩子。

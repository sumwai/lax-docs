这里只做索引：每个词的一句话解释在表里，完整规则在右侧链接指向的小节。命令行输出里的「厂商」与本文的「供应商」是同一样东西。

## 概念

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| API key | 供应商签发的凭据，加密后存在本地 SQLite | [添加账号](/docs/accounts#添加账号) |
| 供应商 | 一家上游服务，由 base URL、若干路由与默认协议组成 | [查看已配置供应商](/docs/providers#查看已配置供应商) |
| 账号 | 一份凭据加一组上游模型；同一供应商可配多个 | [添加账号](/docs/accounts#添加账号) |
| 路由 | 供应商上某种协议对应的请求地址，可含 `{model}` 占位符 | [新增供应商](/docs/providers#新增供应商) |
| 线协议 | 客户端与上游各自说的报文格式：anthropic、openai-chat、openai-responses、gemini、systemone | [五条入站路径](/docs/gateway#五条入站路径) |
| 入站协议 | 客户端连进来时用的协议，由请求路径决定 | [五条入站路径](/docs/gateway#五条入站路径) |
| 出站协议 | 网关发往上游时用的协议，按模型的探测结果、模型声明的协议与供应商默认协议推导 | [五条入站路径](/docs/gateway#五条入站路径) |

## 转发

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 直通 | 入站与出站协议相同，报文原样带到上游，响应按字节返回 | [同协议直通](/docs/gateway/conversion#同协议直通原样带到上游) |
| 统一表示 | 跨协议时先把两边报文翻成一种中立结构，再编成目标协议 | [跨协议转换](/docs/gateway/conversion#跨协议转换只搬映射表里的字段) |
| 映射表 | 跨协议时允许搬运的字段清单，表外字段丢弃 | [跨协议转换](/docs/gateway/conversion#跨协议转换只搬映射表里的字段) |
| 附加请求头 | 声明在供应商上、每条上游请求都要带的头 | [附加请求头](/docs/providers/headers) |

## 决策请求

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 决策请求 | systemone 协议下的一次请求：一份材料加一组问题，返回每个问题的答案与概率，不出文本 | [决策请求](/docs/gateway/decision) |
| state | 决策请求里被判断的那份材料，纯文本与 JSON 都收 | [决策请求](/docs/gateway/decision) |
| 问题类型 | 每个问题的类型：`noul` 是/否、`choice` 选一、`score` 评分 | [三种问题类型](/docs/gateway/decision#三种问题类型) |

## 选号与状态

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 模型清单 | 上游公布的模型名列表，`model sync` 读取 | [同步模型清单](/docs/models#同步模型清单) |
| 同步 | 把上游清单写进本地，不消耗 token，也不判定可用性 | [同步模型清单](/docs/models#同步模型清单) |
| 探测 | 逐个模型发一条真实请求，判定是否可用；对话模型发 `max_tokens=1`，决策模型发最小决策请求 | [探测可用性](/docs/models#探测可用性) |
| 选号 | 按模型名筛出候选账号后，按 `priority` 与冷却挑一个 | [选号依据](/docs/models#选号依据) |
| 冷却 | 账号因上游报错暂停接请求的一段时间，随连续失败翻倍 | [冷却与失败转移](/docs/accounts/failover#冷却与失败转移) |
| 会话粘性 | 同一会话键在一段时间内落到同一账号 | [会话粘性](/docs/accounts/failover#会话粘性) |

## 计价

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 模型单价 | 模型的价格，单位每百万 token，归属在「供应商 × 模型」上 | [模型单价](/docs/models#模型单价) |
| 供应商级标价 | 目录里某家供应商某个模型的一份价，这家供应商的账号都读它；命令输出写作「厂商级标价」 | [模型单价](/docs/models#模型单价) |
| 账号覆盖价 | 只对一个账号生效的价格，账号签的是套餐价时用；清掉就回到供应商级标价 | [模型单价](/docs/models#模型单价) |
| 未定价 | 这一项没有价格：花费显示 `未定价`、`cost` 为 `null`，与免费的 `0` 是两件事 | [模型单价](/docs/models#模型单价) |

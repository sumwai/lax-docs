---
title: 选号
description: 从候选账号到最终顺序，以及如何观察一次选号
---

选号是网关在一次请求里挑账号的过程。它只改账号顺序，不碰上游协议、请求体或响应体。

## 三层设置

| 层级 | 作用 | 命令 |
| --- | --- | --- |
| 默认策略 | 没有模型覆盖时使用 | `lax route set --default` |
| 模型策略 | 只对这一个真实模型生效 | `lax route set <模型>` |
| 账号权重 | 给 `weighted` 与 `softmax` 的输入 | `lax route account set` |

模型策略优先于默认策略；模型没有覆盖时回落到默认；默认也没写过时使用内置策略。

## 内置默认

| 项 | 值 |
| --- | --- |
| 策略 | `priority` |
| 会话粘性 | `prefer` |
| 温度 | `0.1` |
| 探索 | `2%` |
| 统计窗口 | `1d` |
| 最小样本 | `20` |
| 评分权重 | 优先级 0.4、成功率 0.5、延迟 0.1 |

## 操作

```bash
lax route ls
lax route show glm-4.6
lax route show --default
lax route set glm-4.6 --strategy weighted
lax route unset glm-4.6
lax route explain glm-4.6 --session demo --seed 42
```

| 命令 | 作用 |
| --- | --- |
| `route ls` | 列出默认策略与全部模型覆盖 |
| `route show` | 看一个目标最终生效的完整设置 |
| `route set` | 写一条策略，**整条覆盖** |
| `route unset` | 删除一条策略，回落到默认或内置默认 |
| `route account` | 查看或修改账号权重 |
| `route explain` | 预演一次选号，不发上游、不写记录 |

`route set` 是整条覆盖：没写的参数取内置默认，而不是保留原值。例如原本设置了 `--min-samples 50`，下一次只写 `--strategy rotate`，最小样本会回到 20。

## 目标名与别名

`route set` 与 `route show` 接受模型名。写了别名时，命令会先解析到真实模型名，再写入。策略只挂在真实模型上，因此客户端用别名请求也会命中同一条策略。

`route show <别名>` 显示的是解析后真实模型的设置。`route ls` 只列真实模型。

## 改完立即生效

策略存在数据库里，网关每次请求都读当前快照，不需要重启。`route explain` 读的是同一份快照与统计，所以能预演线上会选择谁。

## 与冷却的关系

选号策略决定候选顺序；冷却决定候选是否存在。即使 `priority` 最小的账号排在第一，只要它正在冷却，就会被排除，顺序从下一个开始。

冷却按“账号 + 模型”记录。一个账号的一个模型被限流，不影响这个账号的其它模型，也不影响其它账号的同一个模型。

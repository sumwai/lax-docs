---
title: 快速开始
description: 5 分钟内设置 API Key、查询可用模型并发起第一条对话
---

开始前需要两项信息：网关地址 [https://larkax.com](https://larkax.com) 与管理员发放的 `API Key`。

尚未取得凭据时，请先查看[取得凭据](/#取得凭据)。

## 1. 设置环境变量

将 `API Key` 存入环境变量 `$OPENAI_API_KEY`，避免凭据反复出现在终端命令或脚本里。

变量值只需填写原始字符串，无需添加 `Bearer ` 前缀。

```bash
export OPENAI_API_KEY='<API Key>'
```

## 2. 验证可用模型列表

发送 `GET /v1/models` 请求，确认 `API Key` 生效并查看当前可用模型。

返回结果中的 `data[].id` 就是后续请求需要填写的模型名。

```bash
curl -s https://larkax.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"
```

预期返回示例：

```json
{
  "object": "list",
  "data": [
    {
      "id": "deepseek/deepseek-v4.1-flash",
      "object": "model",
      "created": 0,
      "owned_by": "deepseek"
    }
  ]
}
```

该接口仅用于只读查询，不会产生对话计费。

## 3. 发起第一条对话

使用 `deepseek/deepseek-v4.1-flash` 发送一条非流式对话请求，确认链路完全通畅：

```bash
curl -s https://larkax.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "deepseek/deepseek-v4.1-flash",
    "messages": [{"role": "user", "content": "用一句话介绍 HTTP"}]
  }'
```

预期成功输出示例：

```json
{
  "id": "chatcmpl-example",
  "object": "chat.completion",
  "created": 1700000000,
  "model": "deepseek/deepseek-v4.1-flash",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "HTTP 是在客户端与服务器之间传输超文本与结构化数据的应用层协议。"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 22,
    "total_tokens": 34
  }
}
```

提取返回结果中的 `choices[0].message.content` 即可获得回复内容。

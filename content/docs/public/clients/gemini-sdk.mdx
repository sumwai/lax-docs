---
title: Gemini SDK
description: 用 Google Gen AI SDK 或 HTTP 连接 larkax 的 gemini 入口
---

Gemini SDK 使用 gemini 协议。模型名在 URL 路径里，base URL 指向 `https://larkax.com`。

## 配置

示例里的模型名要换成 `GET /v1/models` 返回的名字，下面用 `deepseek-v4-pro` 举例。

```python
from google import genai

client = genai.Client(
    api_key="<API Key>",
    http_options={"base_url": "https://larkax.com"},
)
resp = client.models.generate_content(
    model="deepseek-v4-pro",
    contents="hello",
)
```

网关接受原生 `generateContent` 与 `streamGenerateContent` 路径。

## HTTP 示例

客户端不接受自定义 base URL 时，可以直接请求：

```bash
curl -s https://larkax.com/v1beta/models/deepseek-v4-pro:generateContent \
  -H 'x-goog-api-key: <API Key>' \
  -H 'Content-Type: application/json' \
  -d '{"contents":[{"parts":[{"text":"hello"}]}]}'
```

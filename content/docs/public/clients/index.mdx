---
title: 选择客户端
description: 按客户端选择 base URL 与 API Key 的放置方式
---

larkax 的默认入口是 `https://larkax.com`。客户端把 base URL 指向这里，用 API Key 鉴权，不需要在本机安装或启动网关。

## 选择客户端

| 客户端 | 页面 | base URL |
| --- | --- | --- |
| Claude Code | [Claude Code](/clients/claude-code) | `https://larkax.com` |
| Codex | [Codex](/clients/codex) | `https://larkax.com/v1` |
| OpenAI SDK | [OpenAI SDK](/clients/openai-sdk) | `https://larkax.com/v1` |
| Anthropic SDK | [Anthropic SDK](/clients/anthropic-sdk) | `https://larkax.com` |
| Gemini SDK | [Gemini SDK](/clients/gemini-sdk) | `https://larkax.com` |

所有客户端共用同一套地址与鉴权规则，差异只在 base URL 是否包含 `/v1`，以及客户端使用的请求头。

## 凭据与请求头

凭据由入口管理员发放，取得方式见[取得凭据](#取得凭据)。三种请求头的完整写法见[凭据与请求头](/auth#三种请求头)。

[https://larkax.com](https://larkax.com) 是托管好的模型网关，无需在本地安装软件或维护上游账号。

只需拿到一套 `API Key`，就能在 Claude Code、Codex、OpenAI SDK、Anthropic SDK 与 Gemini SDK 中使用统一地址调用各类模型。

不同工具使用的接口协议各不相同：Claude Code 与 Anthropic SDK 使用 `anthropic` 协议，Codex 使用 `openai-responses` 协议，OpenAI SDK 使用 `openai-chat` 协议，Google Gen AI SDK 使用 `gemini` 协议。

网关会在后台自动完成协议转换，并在多条上游线路之间自动切换可用线路，客户端切换模型时无需修改代码。

```text
Claude Code ──┐
Codex ────────┼── API Key ──→ https://larkax.com ──→ 自动转换协议并切换可用线路 ──→ 上游供应商
主流 AI SDK ──┘
```

## 取得凭据

`API Key` 由网关管理员统一发放。

拿到 `API Key` 后，只需将其写入客户端配置或环境变量即可开始调用。

- **客户端调用接口**：将 `API Key` 放入请求头，用于访问 `/v1/...` 与 `/v1beta/...` 接口。
- **浏览器直接访问**：直接打开 [https://larkax.com](https://larkax.com) 时使用的是 Basic 认证的用户名与密码，该凭据仅用于网页访问，不能用于 API 调用。

## 注意事项

- 请将 `API Key` 保存在环境变量或本地客户端配置文件中，避免提交到公开代码仓库、写入前端页面或放进 URL 查询参数。
- 可用模型与线路状态会动态变化，接入前建议通过 `GET /v1/models` 核对当前可用模型名。

<Callout type="info" title="服务边界">
[https://larkax.com](https://larkax.com) 专注于请求转发与多线路调度，凭据与使用范围由网关管理员统一约定，因此不提供自助注册、在线充值或个人网页控制台。

网关仅转发请求并统计基础用量，不保存对话正文或上传文件。
</Callout>

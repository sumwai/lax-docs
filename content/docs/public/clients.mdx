所有客户端共用同一网关地址 [https://larkax.com](https://larkax.com) 与同一套 `API Key`，区别仅在于 `Base URL` 是否包含 `/v1`，以及客户端使用的认证请求头。

## 客户端速查表

| 客户端 | 协议 | Base URL | 是否带 `/v1` | 请求头 | 详情 |
| --- | --- | --- | --- | --- | --- |
| Claude Code | `anthropic` | `https://larkax.com` | 否 | `x-api-key` | [配置](#claude-code) |
| Codex | `openai-responses` | `https://larkax.com/v1` | 是 | `Authorization: Bearer` | [配置](#codex) |
| OpenAI SDK | `openai-chat` | `https://larkax.com/v1` | 是 | `Authorization: Bearer` | [配置](#openai-sdk) |
| Anthropic SDK | `anthropic` | `https://larkax.com` | 否 | `x-api-key` | [配置](#anthropic-sdk) |
| Gemini SDK | `gemini` | `https://larkax.com` | 否 | `x-goog-api-key` | [配置](#gemini-sdk) |

下文示例均先在终端设置环境变量 `export OPENAI_API_KEY='<API Key>'`，并使用 `deepseek/deepseek-v4.1-flash` 作为示例模型。

实际调用前可通过 `GET /v1/models` 查看当前可用模型列表。

## Claude Code

Claude Code 使用 `anthropic` 协议，`ANTHROPIC_BASE_URL` 必须填写不带 `/v1` 的根地址，否则客户端会拼接出 `/v1/v1/messages` 并返回 `404`。

设置环境变量并启动：

```bash
export ANTHROPIC_BASE_URL=https://larkax.com
export ANTHROPIC_AUTH_TOKEN="$OPENAI_API_KEY"
export ANTHROPIC_MODEL=deepseek/deepseek-v4.1-flash
claude
```

验证连通性：

```bash
curl -s https://larkax.com/v1/messages \
  -H "x-api-key: $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4.1-flash","max_tokens":16,"messages":[{"role":"user","content":"hi"}]}'
```

## Codex

Codex 使用 `openai-responses` 协议，`base_url` 必须包含 `/v1`。

编辑 `~/.codex/config.toml`，并确保 `model_provider` 与 `[model_providers.<name>]` 的键名一致：

```toml
model = "deepseek/deepseek-v4.1-flash"
model_provider = "larkax"

[model_providers.larkax]
name = "larkax"
base_url = "https://larkax.com/v1"
env_key = "OPENAI_API_KEY"
```

设置环境变量并启动：

```bash
export OPENAI_API_KEY='<API Key>'
codex
```

验证连通性：

```bash
curl -s https://larkax.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4.1-flash","input":"hi"}'
```

## OpenAI SDK

OpenAI SDK 使用 `openai-chat` 协议，会自动拼接 `/chat/completions`，因此 `Base URL` 必须包含 `/v1`。

Python 示例：

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://larkax.com/v1",
    api_key=os.environ["OPENAI_API_KEY"],
)

resp = client.chat.completions.create(
    model="deepseek/deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "hello"}],
)
print(resp.choices[0].message.content)
```

Node.js 示例：

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://larkax.com/v1",
  apiKey: process.env.OPENAI_API_KEY,
});

const resp = await client.chat.completions.create({
  model: "deepseek/deepseek-v4.1-flash",
  messages: [{ role: "user", content: "hello" }],
});
console.log(resp.choices[0].message.content);
```

验证连通性：

```bash
curl -s https://larkax.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4.1-flash","messages":[{"role":"user","content":"hi"}]}'
```

## Anthropic SDK

Anthropic SDK 使用 `anthropic` 协议，会自动拼接 `/v1/messages`，因此 `base_url` 不要包含 `/v1`。

此外，`max_tokens` 是该协议的必填参数，缺失时会返回 `400`。

Python 示例：

```python
import os
from anthropic import Anthropic

client = Anthropic(
    base_url="https://larkax.com",
    api_key=os.environ["OPENAI_API_KEY"],
)

msg = client.messages.create(
    model="deepseek/deepseek-v4.1-flash",
    max_tokens=256,
    messages=[{"role": "user", "content": "hello"}],
)
print(msg.content[0].text)
```

验证连通性：

```bash
curl -s https://larkax.com/v1/messages \
  -H "x-api-key: $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4.1-flash","max_tokens":16,"messages":[{"role":"user","content":"hi"}]}'
```

## Gemini SDK

Gemini SDK 使用 `gemini` 协议，模型名位于请求路径中，`http_options.base_url` 填写不带 `/v1` 或 `/v1beta` 的根地址。

Python 示例：

```python
import os
from google import genai

client = genai.Client(
    api_key=os.environ["OPENAI_API_KEY"],
    http_options={"base_url": "https://larkax.com"},
)

resp = client.models.generate_content(
    model="deepseek/deepseek-v4.1-flash",
    contents="hello",
)
print(resp.text)
```

验证连通性：

```bash
curl -s https://larkax.com/v1beta/models/deepseek/deepseek-v4.1-flash:generateContent \
  -H "x-goog-api-key: $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"contents":[{"parts":[{"text":"hello"}]}]}'
```

## 流式输出与常用参数

### 流式输出

四条对话协议均支持 SSE 流式输出。

OpenAI SDK 与 Anthropic SDK 设置 `stream=True`，Gemini SDK 调用 `:streamGenerateContent` 接口。

```bash
curl -N https://larkax.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "deepseek/deepseek-v4.1-flash",
    "stream": true,
    "messages": [{"role": "user", "content": "数到五"}]
  }'
```

流式响应一旦开始向客户端输出内容，中途连接中断不会自动续传或切换线路重新发送已输出的片段，需要由客户端重新发起完整请求。

### 工具调用

OpenAI、Anthropic、Gemini 与 Responses 四条协议之间的工具定义、工具调用与工具结果会随消息一并转换。

不同协议独有的扩展字段不会跨协议透传，上线新模型前建议先用最小工具样例验证一次。

```python
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询城市天气",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"],
        },
    },
}]

resp = client.chat.completions.create(
    model="deepseek/deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "北京天气如何？"}],
    tools=tools,
)
```

### 会话粘性

同一模型背后可能有多条上游线路。

如果希望同一段多轮对话尽量固定在同一条可用线路上以提高缓存命中率，可以在请求头传入稳定的会话标识，或在支持的请求体中设置 `metadata.user_id`：

```bash
-H 'x-lax-session: conversation-42'
```

`x-lax-session` 仅用于网关调度，不会透传给上游供应商。

当对应线路暂时不可用时，网关仍会自动切换到其他可用线路。

### 其他接口与模型别名

除对话外，网关还提供向量化与语音接口，请求体大小上限均为 32 MiB：

| 用途 | 路径 | 说明 |
| --- | --- | --- |
| OpenAI 向量化 | `POST /v1/embeddings` | 仅同协议原样转发 |
| Gemini 向量化 | `POST /v1beta/models/{model}:embedContent` | 模型名位于 URL 路径中 |
| 语音合成 | `POST /v1/audio/speech` | 需要目标模型支持语音合成 |
| 语音转写 | `POST /v1/audio/transcriptions` | 需要目标模型支持语音转写 |

网关可能配置了模型别名，传入别名时会自动解析为实际模型，因此响应中的 `model` 字段可能返回解析后的真实模型名。

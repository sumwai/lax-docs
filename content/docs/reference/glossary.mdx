## 对象

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 供应商 | 一家上游服务，包含地址、路由、默认协议与凭据头写法 | [供应商与路由](/docs/self-hosted/configure/providers) |
| 账号 | 一份上游凭据，挂在某家供应商上 | [账号](/docs/self-hosted/configure/accounts) |
| 路由 | 某条线协议对应的上游地址 | [供应商与路由](/docs/self-hosted/configure/providers) |
| 模型目录 | 上游曾公布或手工声明的模型与元数据 | [模型管理](/docs/self-hosted/configure/models) |
| 可达性 | 某个账号上的某个模型是否能用于转发 | [模型与账号](/docs/concepts/models-accounts) |
| 别名 | 客户端写死的模型名指向真实模型名 | [模型与账号](/docs/concepts/models-accounts) |
| 能力位 | 模型能用于哪类端点：chat、embedding、speech、transcription | [模型与账号](/docs/concepts/models-accounts) |

## 协议与转发

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 线协议 | 客户端与上游交换请求的报文格式 | [线协议](/docs/self-hosted/gateway/protocols) |
| 入站协议 | 客户端连进来时使用的协议，由路径决定 | [线协议](/docs/self-hosted/gateway/protocols) |
| 出站协议 | 网关发往上游时使用的协议，由模型与供应商推导 | [线协议](/docs/self-hosted/gateway/protocols) |
| 直通 | 入站与出站协议相同，报文原样转发 | [协议转换](/docs/self-hosted/gateway/conversion) |
| 中间表示 | 跨协议转换时的中立结构 | [协议转换](/docs/self-hosted/gateway/conversion) |
| 方言 | 某个模型在某条操作上的上游报文形状 | [方言](/docs/self-hosted/plugins/dialects) |

## 选号与状态

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 选号 | 在一次请求里挑选账号的过程 | [选号](/docs/self-hosted/route) |
| 候选 | 满足启用、提供该模型、未冷却的账号 | [请求生命周期](/docs/concepts/request-lifecycle) |
| 冷却 | 账号在某个模型上失败后被暂时移出候选的时间 | [请求生命周期](/docs/concepts/request-lifecycle) |
| 会话粘性 | 同一会话键是否固定到同一账号 | [选号策略](/docs/self-hosted/route/policies) |
| 权重 | 账号在 weighted 与 softmax 里的分流比例 | [账号权重](/docs/self-hosted/route/weights) |
| 平滑成功率 | 加入最小样本后的成功率，避免零样本排到最后 | [选号策略](/docs/self-hosted/route/policies) |

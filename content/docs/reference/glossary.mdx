术语速查，不是教程。

每个词只给一句话定义与权威小节；概念与数据流见[工作原理](/self-hosted/concepts/how-it-works)。

## 对象

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 供应商 | 一家上游服务，包含地址、路由、默认协议与凭据头写法 | [供应商与路由](/self-hosted/configure/providers) |
| 账号 | 一份上游凭据，挂在某家供应商上 | [账号](/self-hosted/configure/accounts) |
| 路由 | 某条报文协议对应的上游地址 | [供应商与路由](/self-hosted/configure/providers) |
| 模型目录 | 上游曾公布或手工声明的模型与元数据 | [模型管理](/self-hosted/configure/models) |
| 可达性 | 某个账号上的某个模型是否能用于转发 | [模型管理](/self-hosted/configure/models) |
| 别名 | 客户端写死的模型名指向真实模型名 | [模型管理](/self-hosted/configure/models) |
| 声明的能力 | 模型能用于哪类端点：`chat`、`embedding`、`speech`、`transcription` | [模型管理](/self-hosted/configure/models) |

## 选号与状态

| 术语 | 一句话 | 详见 |

| 冷却 | 账号在某个模型或账号级别失败后被暂时移出候选的时间 | [冷却、重试与选号排障](/self-hosted/route/failure#冷却范围与选号) |

## 额度

| 术语 | 一句话 | 详见 |
| --- | --- | --- |
| 账号额度 | 上游账号的余额与到期时间，只读监控，不是按最终用户分配的配额 | [额度感知与优先消耗](/self-hosted/route/quota) |
| 额度快照 | 最近一次刷新留下的账号额度明细，一个账号一行 | [手动刷新与自动刷新](/self-hosted/route/quota#手动刷新与自动刷新) |
| 剩余比例 | 余额 ÷ 总额；总额未知时也算未知 | [CommandCode](/self-hosted/route/quota#commandcode) |
| 折合 USD | 把原币种按手工汇率折成美元后的值 | [金额与币种](/self-hosted/route/quota#金额与币种) |
| 监控来源 | `auto`、`commandcode`、`deepseek` 或 `off` | [监控设置](/self-hosted/route/quota#监控设置) |
| 额度排序 | 策略、粘性与 softmax 之后对完整顺序做的稳定排序 | [参与选号](/self-hosted/route/quota#参与选号) |
| 最低折合余额 | `--quota-min-usd`，排除已知折合余额低于阈值的账号 | [参与选号](/self-hosted/route/quota#参与选号) |
| 到期处理 | `warn` 只提示、`deprioritize` 排到末尾、`exclude` 排除 | [到期处理](/self-hosted/route/quota#到期处理) |
| 限流窗口 | CommandCode 的 5 小时与每周窗口，不是月度总额 | [CommandCode](/self-hosted/route/quota#commandcode) |
| 上游用量 | 上游统计的所有客户端合计，仅供查看 | [CommandCode](/self-hosted/route/quota#commandcode) |

## 配额

配额指按最终用户分配与扣减的多租户额度。

lax 不提供多租户与配额分配；管理员侧对上游账号的只读余额与到期时间叫[账号额度](/self-hosted/route/quota)，不是配额。

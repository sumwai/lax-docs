---
title: OpenAI SDK
description: 用 Python 或 Node.js 的 OpenAI SDK 连接 larkax
---

OpenAI SDK 使用 openai-chat 协议。把 base URL 指向 `https://larkax.com/v1`，api key 填入口 token。

## Python

```python
from openai import OpenAI

client = OpenAI(base_url="https://larkax.com/v1", api_key="<token>")
resp = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[{"role": "user", "content": "hello"}],
)
print(resp.choices[0].message.content)
```

## Node.js

```js
import OpenAI from "openai";

const client = new OpenAI({ baseURL: "https://larkax.com/v1", apiKey: "<token>" });
const resp = await client.chat.completions.create({
  model: "deepseek-v4-pro",
  messages: [{ role: "user", content: "hello" }],
});
```

OpenAI SDK 会自己拼接 `/chat/completions`，因此 base URL 要包含 `/v1`。

## 验证

```bash
curl -s https://larkax.com/v1/chat/completions \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v4-pro","messages":[{"role":"user","content":"hi"}]}'
```

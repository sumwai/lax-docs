---
title: 模型别名
description: 客户端写死的模型名指向真实模型名，匹配、链与冲突规则
---

客户端里写死的模型名不必改：给那个名字配一个别名，指到真实模型名上。

```bash
lax model alias set fast glm-4.6   # 客户端请求 fast 时按 glm-4.6 走
lax model alias ls                 # 别名、目标、状态、解析结果
lax model alias unset fast
```

命令的参数与输出列见[模型命令](/docs/cli/model#alias-set)。

| 项 | 规则 |
| --- | --- |
| 匹配 | 精确匹配，区分大小写，不做通配与前缀归一 |
| 链 | 别名可指向另一个别名，最长 8 跳，成环时请求报 400 并指出环上的名字 |
| 冲突 | 别名不得与任何真实模型名同名（目录里有或某账号正在用），否则会遮蔽真名 |
| 作用方向 | 只影响请求：选号、请求体、路径用真名 |
| 响应里的模型名 | 仍是上游的真实名字，不改写 |
| 请求记录 | `log tail` 的模型列写成 `fast → glm-4.6`，`--json` 里 `model` 是别名、`model_used` 是真名 |
| `/v1/models` | 真实名字与别名都列出，别名的 `owned_by` 取目标模型所属供应商，解析不到目标的不列 |

目标眼下没有账号提供也能先写，之后加账号即生效；解析不了时这条别名不参与选号，`model alias ls` 的状态列写 `不可解析`。

探测产生的请求会写入请求记录，但不计入 [`usage` 的用量汇总](/docs/usage#用量汇总)。

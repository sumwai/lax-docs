---
title: 系统命令
description: init、serve、doctor、version 的参数、输出与检查项
---

这四个命令不操作账号与模型，负责本机环境的初始化、运行与自检。

## init

```bash
lax init
lax init --force
```

创建配置目录、数据库与加密密钥，目录权限为 `0700`。

| 参数 | 说明 |
| --- | --- |
| `--force` | 覆盖已有配置文件；数据库与密钥不重建 |

| 写入项 | 路径 |
| --- | --- |
| 配置文件 | `$XDG_CONFIG_HOME/lax/config.json` |
| 数据库 | `$XDG_DATA_HOME/lax/lax.db` |
| 加密密钥 | 数据库同目录下的 `secret.key` |

配置文件已存在且没给 `--force` 时保留原文件；数据库不存在时创建并执行迁移；密钥不存在时生成。

人读输出三行路径，最后一行给出加账号的下一步。`--json` 输出：

| 字段 | 内容 |
| --- | --- |
| `config` | 配置文件路径 |
| `db` | 数据库路径 |
| `key` | 密钥路径 |

初始化不访问上游，也不需要先有账号。

## serve

```bash
lax serve
lax serve --addr 127.0.0.1:9000
```

前台运行网关，按 Ctrl-C 或 SIGTERM 结束。

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--addr` | 监听地址，留空用配置文件里的值 | `127.0.0.1:4567` |

启动时只读本地数据库，统计账号与模型数量，不向上游发起请求。监听失败（端口被占用、地址不合法）时报错并以退出码 1 结束。

人读输出监听地址、五条入站路径与账号 / 模型计数：

```text
监听 127.0.0.1:4567
入站 /v1/messages（anthropic） /v1/chat/completions（openai-chat） /v1/responses（openai-responses）
上游 3 个账号，47 个模型
```

`--json` 在开始服务前输出一次：

| 字段 | 内容 |
| --- | --- |
| `addr` | 实际监听地址，端口为 0 时是系统分配的端口 |
| `accounts` | 账号数，含停用账号 |
| `models` | 所有账号模型名的去重数 |

默认只监听回环地址。入站不校验凭据，不适合对外提供服务。

## doctor

```bash
lax doctor
```

逐项检查，不修改任何文件。六项检查：

| 检查项 | 通过条件 | 不通过时的提示 |
| --- | --- | --- |
| 配置文件 | 文件存在 | `不存在，先运行 lax init` |
| 数据目录可写 | 能在数据库目录创建并删除临时文件 | 系统错误原文 |
| 加密密钥 | `secret.key` 存在 | `不存在，先运行 lax init` |
| 配置解析 | 配置文件能解析 | 解析错误原文；通过时备注监听地址 |
| 端口 | 监听地址当前可占用 | 占用或地址错误原文 |
| 数据库 | 能打开并读出账号数 | 数据库错误原文；通过时备注账号数 |

人读输出每行一个检查项：

```text
ok    配置文件     /path/to/config.json
ok    数据目录可写 /path/to/data
ok    加密密钥     权限 0600
ok    配置解析     127.0.0.1:4567
ok    端口         127.0.0.1:4567
ok    数据库       3 个账号
```

有任一项未通过时退出码为 1，stderr 写明未通过项数。网关无法启动、迁移机器、升级版本时先执行这条命令。

`--json` 输出数组，每项字段：`name`、`ok`、`note`。

## version

```bash
lax version
```

人读输出 `lax <版本号>`。`--json` 字段：`name`、`version`。

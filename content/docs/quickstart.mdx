---
title: 快速开始
description: 六条命令从零到第一条请求
---

假定已完成[安装与初始化](/docs/install)。下面六步各一条命令。账号名 `ds` 自取，后文跟着改。

## 1. 添加账号

```bash
lax account add ds --provider deepseek --key sk-xxx
```

`--provider` 用内置供应商名即可，不必填 `--base-url`。凭据也可从标准输入或环境变量读取，报错与参数见[添加账号](/docs/accounts#添加账号)。

## 2. 同步模型清单

```bash
lax model sync --account ds
```

只读上游清单，不消耗 token。同步完的模型还不能用，下一步才判定。

## 3. 探测可用性

```bash
lax model probe --account ds
```

对每个模型发一条真实请求（对话模型是 `max_tokens=1` 的请求，决策模型是最小决策请求），通过的才参与选号。想先试通再全量，用 `--limit 3`。判定规则见[探测可用性](/docs/models#探测可用性)。

## 4. 启动网关

```bash
lax serve
```

默认监听 `127.0.0.1:4567`，前台运行。换地址用 `--addr`，详见[启动网关](/docs/gateway#启动网关)。

## 5. 发一条请求

```bash
lax call "用一句话介绍你自己" --model deepseek-v4-pro
```

`call` 自起临时网关，不必先跑 `serve`；加 `--debug` 可看选号过程。要打真实 HTTP 入口：

```bash
curl -s http://127.0.0.1:4567/v1/messages \
    -H 'content-type: application/json' \
    -H 'x-api-key: lax-local' \
    -d '{"model":"deepseek-v4-pro","max_tokens":64,"messages":[{"role":"user","content":"hi"}]}'
```

本机不校验入站凭据，请求头填任意非空值即可。

## 6. 接入客户端

把客户端的 base URL 指向 `http://127.0.0.1:4567`，模型名取探测通过的名称。各客户端配置见[客户端接入](/docs/clients)。

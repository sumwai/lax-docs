---
title: 直接使用 larkax.com
description: 获取 token、填入客户端并发出第一条请求
---

larkax 提供托管入口 `https://larkax.com`。客户端把 base URL 指向这里，用 token 鉴权，不需要在本机安装或启动网关。

## 1. 取得 token

入口接受三种凭据头，值都是同一个 token：

| 客户端 | 请求头 |
| --- | --- |
| OpenAI SDK、Codex、curl | `Authorization: Bearer <token>` |
| Anthropic SDK、Claude Code | `x-api-key: <token>` 或 `Authorization: Bearer <token>` |
| Gemini SDK | `x-goog-api-key: <token>` |

token 由网关管理员提供。浏览器直接打开 `https://larkax.com` 时会走 Basic 认证，用管理员给的用户名与密码；API 客户端应使用上面的三种请求头。

## 2. 配置客户端

| 客户端 | base URL |
| --- | --- |
| Claude Code / Anthropic SDK | `https://larkax.com` |
| Codex / OpenAI SDK / OpenAI Responses | `https://larkax.com/v1` |
| Gemini SDK | `https://larkax.com` |

完整示例见[客户端接入](/docs/hosted/clients)。

## 3. 发第一条请求

```bash
curl -s https://larkax.com/v1/chat/completions \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v4-pro","messages":[{"role":"user","content":"hi"}]}'
```

模型名由上游与管理员配置决定。不知道有哪些模型时，查询模型清单：

```bash
curl -s https://larkax.com/v1/models \
  -H 'Authorization: Bearer <token>'
```

## 4. 查看入口状态

```bash
curl -s https://larkax.com/healthz \
  -H 'Authorization: Bearer <token>'
```

`healthz` 返回账号、启用账号、模型与协议计数，不探测上游。
